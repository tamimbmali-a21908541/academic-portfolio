# Programming Fundamentals

> First principles of programming — variables, control flow, functions, arrays, and decomposition.

**Grade:** 14/20 · **ECTS:** 6 · **Year:** 1 · **Institution:** Universidade Lusófona

---

## Topics studied

- Variables, types, and expressions
- Control flow — conditionals and loops
- Functions, parameters, and scope
- Arrays and strings
- Recursion
- Problem decomposition and algorithmic thinking

## Why it matters

The entry point to everything else in the degree. The habits formed here — decomposing a problem before writing code, naming things clearly, tracing execution by hand — carried through to every project that followed.
