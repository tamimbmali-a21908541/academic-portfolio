# Human-Machine Interaction

> Heuristic evaluation of digital interfaces, and a mobile app prototype for the Lisbon Metro taken through usability and accessibility testing in Axure.

**Grade:** 11/20 · **ECTS:** 5 · **Year:** 3 · **Institution:** Universidade Lusófona

---

## Overview

Two complementary halves: systematically critiquing existing interfaces against established usability principles, then designing one and subjecting it to the same scrutiny.

## What I did

**Heuristic evaluation**
- Assessed digital interfaces against recognised usability heuristics
- Identified and severity-rated violations
- Produced structured findings rather than opinion

**Prototype design — Lisbon Metro mobile app**
- Interactive prototype built in **Axure RP**
- **Usability testing** with task-based scenarios
- **Accessibility** evaluation — contrast, target sizing, screen-reader considerations

## Key takeaways

- **Heuristic evaluation finds different problems than user testing.** Experts catch principle violations; users catch the things nobody thought to question. Both are needed.
- **Prototyping before building is leverage.** Structural interaction problems surface in an Axure click-through in hours, and would cost weeks to fix in code.
- **Accessibility is a design constraint, not a remediation step.** Retrofitted contrast and touch targets compromise a layout; designed-in ones don't.
