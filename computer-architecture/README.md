## Topics studied

**Processor**
- CPU organisation — datapath and control
- Instruction set architecture and addressing modes
- The instruction execution cycle
- Pipelining fundamentals

**Memory**
- The memory hierarchy
- Cache organisation, locality, and hit/miss behaviour

**Programming**
- Assembly language and the mapping from high-level constructs down to instructions

## Why it matters for software

Understanding the memory hierarchy is what makes performance behaviour predictable rather than mysterious. Cache locality explains why iterating an array beats chasing pointers through a linked list — a difference that showed up concretely in the data-structure choices in [Algorithms and Data Structures](../algorithms-and-data-structures), where pre-sizing contiguous collections measurably outperformed the alternative.
