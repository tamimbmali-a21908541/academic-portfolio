# Data Science

> The data science workflow end to end — descriptive statistics, exploratory analysis, and visualisation, through to supervised and unsupervised learning with proper model evaluation.

**Grade:** 13/20 · **ECTS:** 5 · **Year:** 3 · **Institution:** Universidade Lusófona

---

## Overview

The course followed the actual order of the work: understand the data before modelling it, and evaluate honestly before believing a result.

## Topics studied

**Descriptive statistics**
- Central tendency and dispersion
- Distributions and their properties

**Exploratory data analysis**
- Understanding structure, gaps, and outliers before choosing a model
- Visualisation as an analytical tool rather than a reporting one

**Machine learning**
- **Linear regression** — continuous prediction
- **Logistic regression** — classification
- **Clustering** — unsupervised structure discovery

**Model evaluation**
- Assessing generalisation rather than fit
- Choosing metrics appropriate to the problem

## Key takeaways

- **EDA is not a preliminary step you rush.** The distribution, the missing values, and the outliers determine which models are even applicable.
- **Evaluation methodology decides whether a result means anything.** A model scored on its training data tells you nothing about the next observation.
- **Metric choice encodes what you care about.** Accuracy on imbalanced classes is actively misleading; the metric has to match the cost of each error type.
