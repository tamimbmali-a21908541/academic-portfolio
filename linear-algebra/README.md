## Why it matters for software

Linear algebra is the computational substrate of graphics and machine learning. The geometric transformations implemented pixel-by-pixel in [Image Processing](../image-processing) — rotation, scaling, translation — are matrix multiplications. Convolution kernels are matrices. And the entire training loop of a neural network in [Artificial Intelligence](../artificial-intelligence) is matrix arithmetic at scale.
